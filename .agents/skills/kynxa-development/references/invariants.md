# 交互和数据约定

这些约定描述当前基线。用户要求调整其中行为时，同步修改相关实现和验证；其余行为继续保持。详细入口见 [前端维护说明](../../../../apps/desktop/UI-COMPONENTS.md)、[聊天与工作记忆](../../../../docs/architecture/chat-work-memory.md) 和 [原生网关入口](../../../../apps/agent-core/src/gateway.rs)。

## 侧栏、窗口与语言

- 最近、项目树、任务引用同一稳定聊天 ID 和同一记录，不能创建副本。任务显示当前工作聊天，剩余高度延伸至底部固定栏，超出才滚动。
- 项目选择和展开是独立状态；选择聊天、发送、重试、在任务中新增聊天不自动展开已折叠项目。最近默认收起，保留用户展开偏好。
- 新聊天先为内存草稿，立即在相应任务区显示；未发消息切换到其他工作时清理。首条消息提交成功后才正式保存并更新最近/未置顶顺序，单纯打开或切换聊天不更新 MRU。
- 置顶、手动排序、聊天归属与活动选择分别维护。流式开始、结束和 token 更新不重排项目/聊天。
- 悬停、焦点、选中和展开各有独立状态，复用已有按钮、图标、字号与菜单样式。新增操作需有键盘访问和可读自动化名称。
- 侧栏主要入口的悬停／按下直接使用当前配色的共享选中画刷，不出现透明白色插值的亮色闪帧。原生提示、确认、审批及错误对话框使用统一主题画刷、圆角与按钮样式；单个可见操作居中，简短按钮保留适中的点击范围及对称留白，中文确认字距需核对实际文字排版而非只读继承属性。多个操作保留原生分列，保留原有确认语义、键盘默认项和所属窗口。
- 侧栏上下分隔拖动区只在有相关展开内容时存在；移动到分隔区才出现浅灰提示。最近/项目内部的分隔拖动不改变下面任务边界，尺寸受限并支持现有复位行为。
- 窗口临时变窄只约束当前显示尺寸，不覆盖用户保存的宽度。控件尺寸来自布局模块和样式资源，不在多处重复数字。
- 切换界面语言即时更新菜单、设置等界面文字，聊天正文、用户自定义名称、模型 ID、地址和凭据保持原内容。保留草稿、选中项、滚动及进行中的回复。
- 动态本地化使用原生单向绑定持有不引用控件的翻译值源；全局只弱持有值源。原生可视树仍存活而托管控件包装被回收时，文字仍须可更新；切换语言按所属 dispatcher 通知，释放目标后值源可回收。
- 外观与阅读偏好只保存到本机布局；原子保存成功后才应用，失败回滚全部字段。深浅／系统模式与配色ID分别管理，自定义强调色保存原HEX并在展示层调整对比度；高对比度系统颜色优先且不写回偏好。
- 原生ColorPicker只更新待应用HEX输入，点击“应用颜色”后才持久化；待应用草稿跨主题／配色／字号／语言刷新保留，显式应用／清除／恢复默认成功后才重置，失败保留；固定内置ThemeIcon几何只读仓库目录，持有共享语义画刷，不接受用户SVG或HTML，不增加焦点或命中目标。
- 切换主题／字号保留正式正文、选区端点、草稿与会话阅读锚点；字号变化重测12个完整可视行，折叠复制仍为完整源码。延迟字号校正不得覆盖更新的用户导航。WinUI主题通知监听自有HWND并在关闭时解除，不订阅桌面不支持的WinRT主题事件。
- 界面刷新按稳定 ID 保留行对象；不要在输入回调中清空整棵 TreeView，避免重复渲染和丢失状态。

主要入口：[WorkSidebarState](../../../../apps/desktop/Services/Presentation/WorkSidebarState.cs)、[工作侧栏](../../../../apps/desktop/Views/ShellPage.WorkSidebar.cs)、[布局状态](../../../../apps/desktop/Models/UI/LayoutState.cs)、[界面文本](../../../../apps/desktop/Services/Presentation/UiText.cs)。

## 聊天展示、选择与流式输出

- Mermaid 图表内容区及 SVG／PNG 导出默认白底，与应用／系统主题和强调色分开；明确源码样式保留，工具栏及源码跟随应用主题。PNG 自动采用现有边长／像素上限内的最大等比尺寸，不提供倍率或透明度选择；主题切换不重建图表、打断选区或重置缩放。

- 工作右栏的整个任务区高度受窗口约束，展开后在内部滚动；文件标签横向排列，预览使用剩余高度。真实文件回执和任务产物共用入口，同路径更新不重复开标签，不抢占用户当前选择；关闭标签只关闭视图。文档与外站 WebView 分开管理，解析和 Office 转换在 Rust 后台执行，不能开放聊天页面的宿主桥以充当浏览器。
- 保存文件只登记资源，不自动打开每份中间产物；模型按用途选择总结、报告、最终成果及当前必要内容，通过明确展示或最终答复中的已知文件链接放入右栏，不以固定数量截断相关产物。用户主动打开、正在阅读的标签及关闭选择受保护，同路径更新复用标签，其余文件仍可从资源列表打开；链接不能自行创造文件事实或猜测同名目标。
- 随包网页窗口作为真正的 `WS_CHILD` 挂入内容行的原生宿主，不能用顶层 owner 与手工 region 模拟内嵌；任务区与文件标签始终在宿主之外。网页遮挡验收要查看正式 Shell 的实际画面，裁剪坐标检查不能替代目视。
- WinUI 网页视口须转交真实鼠标、滚轮和键盘输入，单有 HWND 父子关系或 `HTCLIENT` 不能证明可操作；文字与键消息避免重复派发，中文提交走输入法接收器。窗口失去前台仍保留网页画面，切换标签、最小化及退出再按生命周期隐藏；后台可见性应检查实际画面。
- 用户打开的终端嵌入右栏标签，不启动独立控制台窗口；Rust 负责真实 ConPTY、工作归属校验及进程树，xterm.js 仅负责交互渲染。模型的工作区终端工具与用户界面共享真实会话及输出缓存，收到既有 sessionId 只挂接视图，不重复创建伪终端。切换标签保留会话，关闭终端标签、删除聊天及退出软件释放对应会话；该入口不绕过模型终端工具的权限规则。

- 主聊天由 [ConversationTranscript](../../../../apps/desktop/Controls/ConversationTranscript.cs) 的一个 WebView2 DOM 展示。Markdown、代码、表格与 KaTeX 公式保持可选文字；旧 `MarkdownReply`/原生图片公式只是兼容路径。
- 正式记录保存原始内容，呈现不改写源 Markdown/TeX。普通内容框保留代码行边界，长行在框内横向滚动，正文仍随聊天列换行；复制保留原始换行、连续空行和缩进；公式完整选择复制原 TeX，部分选择复制所选可视内容。
- 用户与模型多条连续回复可跨消息选择。松开鼠标结束拖选，点击非交互空白清除选区；有活动选区时暂缓改变其 DOM，清除后应用最新内容。
- 首次打开或展示缓存不可用时到最下面；返回已有缓存的聊天时恢复离开前的阅读位置及底部跟随状态，首个导航快照不能覆盖已恢复位置。显式跳转到最新消息仍有效。从底部发送后随回复增长，用户主动上滚或选择内容时暂停跟随；不能每次 token 更新无条件滚到底部。
- 流式内容与最终内容走同一展示路径。正文、思考、完成、错误和中断状态分别处理，未闭合公式允许显示源码，最终完整块重新解析。
- 工具回复按模型轮次保存 `AssistantSegments`，公开思考、阶段正文和该轮工具保持真实顺序，最终正文独立。工具调用、审批和结果复用同一 round/order；并发结果可以乱序返回，但不能改变调用身份。正式 `Content` 与阶段原文保留；最终展示依据 `final_answer` 及明确的 `isAnswerContinuation` 标记，不能取最后续写片段或把工具进展混入正文。旧消息缺少标记时保持兼容，不猜测或重写历史。
- 顶部用时从模型、上下文和工具目录准备完成后的首个流式消息段开始，不能从发送或传输 `started` 提前计时。运行中仅每秒更新用时文字，跨工具轮次、聊天切换和语言切换保持单调起点；终态停止刷新，成功时使用网关保存的 `DurationMs`，重新打开不重新计算。本机实时计时起点不写入正式日志。
- 主聊天执行中只展示近期阶段正文与紧凑活动，待批准动作不能被裁掉；完整交付有效最终正文后收束过程，展示正文及真实耗时，任务验收状态独立保留。部分成果不能隐藏最终答复，也不能宣称全部成功；真正失败、取消或截断且没有完整答复时保留过程。复制与重新打开采用相同投影；正式阶段、思考、调用与结果不因隐藏而删除。选区冻结与上滚阅读锚点须在过程收束时保持。
- 快速切换时废弃过期解析结果；缓存有容量、身份和失效边界。保留未变化 DOM，不为新 token 重建整个页面。
- HTML、JS、样式和字体随应用打包。保持现有 Markdown 转义、导航/资源/权限拦截及链接协议限制，不能让回复内容引入脚本或远程资源加载。

主要入口：[TranscriptMarkdown](../../../../apps/desktop/Services/Presentation/TranscriptMarkdown.cs)、[transcript.js](../../../../apps/desktop/Resources/Transcript/transcript.js)、[transcript.css](../../../../apps/desktop/Resources/Transcript/transcript.css)。

## 正式记录与工作关系

- 消息附件原件由 Rust 保存到所属会话目录，正式消息只记录稳定附件描述符；选择路径与缩略图不进入正式消息正文。DOCX/PDF 等由现有解析器后台提取并分页送入当前模型轮；图片沿用多模态协议，文字模型拒绝时保留文本和附件回读入口。附件随会话移动、删除，不因上传自动公开到全局记忆。
- 右侧已打开标签保留已解析内容、渲染与阅读位置；切换时已有加载在后台继续，结果只写入其所属标签。普通切换复用现有页面，显式刷新再更新；关闭标签或删除聊天取消对应工作。缓存有界，淘汰后按需重建。
- 右栏任务进度默认折叠，展开后才读取展示进度；收起不暂停后端任务。网页标签仅使用随包 Chromium，由 Rust 按需启动并统一持有共享进程，不选择系统浏览器。启动恢复网页只恢复标签，明确打开或激活时才加载；浏览器 MCP 不参与启动预热。登录数据按应用持久共享，页面与工具权限仍按聊天隔离；关闭标签或删除聊天不清除登录，只有明确的网站数据清理操作清除。普通打开网站默认右栏，明确启动本机浏览器才使用外部程序。文档渲染仍与网页自动化隔离。地址栏支持网址与关键词，输入中的文字不能被后台地址更新覆盖。文件标签名称及关闭位使用同一背景，宽度固定、超长省略。
- 当前模型的后台准备在主窗口构造前启动，切换模型立即重新调度；不等待目录或索引加载，不逐消息重新准备 API。API 连接预备、模型可用和真实生成验证分别记录，凭据只由后端读取。

- 点击发送后先同步显示用户消息和等待回复占位，再异步保存并连接模型；不能以保存或模型就绪作为显示用户消息的前置条件。正式保存成功且归属、用户消息和取消状态复核通过后才派发模型请求。保存失败保留本次输入并正常结束占位，重试沿原用户/请求 ID 和工作归属提交；等待期间的新草稿不得被保存完成回调清空。
- 网关是正式会话和目录的单一写入所有者。桌面上传元信息和新用户消息，不回写助手快照来覆盖网关生成状态。
- 未发送草稿不创建正式会话、索引条目或记忆文件；打开相关 UI 不能改变这点。
- 工作名、关联路径、模型/服务商切换和 Data 迁移不改变聊天/工作 ID。普通聊天及无文件夹工作有各自身份，不通过显示标题推断归属。
- JSONL 是正式消息事件来源；索引、上下文摘录和项目清单按各自权威来源重建。`catalog.json` 拥有目录元信息，`project.json` 是其投影，不能反向作为独立目录事实。
- 归属、删除、撤销、移动、归档及生成事务经过既有会话队列；不得在旁路直接移动日志后补 UI。
- 单网关拥有 Data 的前提不可悄悄变成多个进程同时写。新增多进程方案需要明确新的并发合同。
- 任务与执行尝试分别拥有稳定 taskId 和递增执行围栏。主聊天与子任务共用正式范围及父预算，子任务独立上下文不写成伪造主聊天消息；已派发的未知副作用先核验，成功回执不能因恢复重放。
- 恢复沿原生证据核验、结算、续接的同一流程，缺证据继续等待；结算后的根回执回填原正式模型轮次，晚于私有工作快照时先回读原记录。侧栏按当前聊天分页列出可恢复根任务并明确选择，模型隐藏展示不能使任务失去恢复入口。
- 已持久接受任务后，SSE 断开或切换聊天只停止观察，用户停止、暂停和恢复通过正式任务控制落盘。子任务进度及审批独立于主回复工具顺序，UI 不因收到新任务事件截断正文。
- 执行中发送默认进入输入框上方的多条队列。点击“引导”立即移除等待项，先前输出保留在上方并停止追加，引导消息后接新回复；调用、结果及同一任务身份继续接续，正式记录保存续接与回复对应关系。停止按钮暂停并保留队列，不额外显示暂停通知。队列比输入框略窄，复用现有样式、圆角和中性焦点，不出现默认蓝框。任务可由模型命名及选择展示，输入/输出 token 和耗时累计不因引导清零；开工说明、重要进展和调整确认由提示词软引导。
- 语义摘要与普通生成共用真实模型准入、预约和结算；失败或未知 token 不记成精确零。任务事件、检查点和原文引用的权威所有者见 [持久任务合同](../../../../docs/architecture/durable-tasks.md)。
- 目录读取可请求 `includeMessages=false` 元信息，正式消息按分页接口读取；页游标绑定聊天归属与日志版本，更新、移动和删除后不得用旧游标读出越界历史。分页不切开单条消息，原始 UTF-16 与私有字段剔除合同仍保持。
- `Status=completed` 仅表示消息传输完成；`ToolRun.taskCompletion` 才记录任务完成、部分完成、核验失败或执行结果未知。历史上下文和摘要身份须携带该状态，不能把已执行但未核验的动作投影为成功，也不因此重派副作用。

主要入口：[正式存储](../../../../apps/agent-core/src/storage/gateway.rs)、[历史分页](../../../../apps/agent-core/src/storage/conversation_history.rs)、[请求生命周期](../../../../apps/agent-core/src/orchestration/gateway_runtime.rs)、[存储布局](../../../../apps/agent-core/src/storage/layout.rs)。

## 记忆、上下文与来源

- 完整聊天历史按聊天 ID 隔离，默认模型上下文不自动加入兄弟聊天原文；同工作通过确认记忆共享约定，关系接口仅返回元信息。用户明确查询同工作历史时，允许 `conversation.history.search` 使用显式 `scope: "work"` 检索正式目录核验的同工作未归档公开消息，并按返回的来源聊天 ID 回读；不扩大到其他工作或全局聊天。
- 核实用户曾说过或问过什么，须依据 `role: "user"` 的正式消息及聊天/消息 ID。助手文字、工作文件和网页快照不能代替用户提问证据；确认记忆为空、搜索失败或覆盖不完整不能证明从未提过。历史回读建议携带消息级 `sourceVersion`，消息及归属改变须重新核验，无关追加不能使旧消息引用自失效；搜索分页游标仍绑定完整日志版本，报告实际覆盖并提供有界续查入口。
- 聊天、工作、用户全局记忆范围独立。隐藏的无文件夹工作不提供共享工作记忆；工作归档后的共享记忆不注入。
- 只有用户明确确认的记忆才能持久化为已确认条目。正式保存的完整开头“记住：”及明确范围指令就是本次内容的授权，不重复询问；普通规则或模型提取保留草稿与原话，由用户确认。助手输出、引用、代码块和普通对话不自动升级为长期事实。记忆读取请求无需再询问是否读取，空记忆不等于空历史；记忆位于应用 Data，不由外部工作文件夹是否存在 memory 文件判断。
- 创建、更新和删除遵循范围版本 `expectedRevision`。冲突重新加载并让用户决定，不自动用旧表单覆盖他人修改。
- 来源归档、删除、撤销和移出工作各有现有有效性规则，状态从后端读取，不把暂停使用误当成条目删除。删除保留撤销标记，旧请求重试不能恢复已删除记忆。
- 上下文预算构建只做请求投影，不截断正式日志。历史选择保留完整有效轮次及助手调用/工具观察配对；失败、中断草稿不当成功答案，已执行动作按真实回执状态保留，不自动重放。可见思考不当最终事实注入；私有原生续接不能进入公开接口或跨来源回放。
- `context.json` 是可重建请求导航缓存，可以包含已校验的语义摘要，不是已确认长期记忆。摘要来源、内容哈希、覆盖历史、任务结果状态和预算绑定实际正式日志；存储提交前重新校验来源，失效缓存安全降级为公开摘录或可回读检查点。旧摘录格式沿相应兼容规则处理，未来版本拒绝覆盖；长期记忆损坏明确失败并保留文件，不能当空记忆写回。
- 1M 只是配置预算，不代表模型自动获得对应能力。输出由 `models/output.rs` 统一计算，连接 `maxOutputTokens` 默认 262144（256K），显式保存的小值继续保留；小上下文、必要输入和已知供应商输出能力会降低实际输出。独立输入硬限须另行夹住，不能把总窗口当输入限。`models/capabilities.rs` 只核对已验证官方端点/精确模型，本地自动调整结合真实观察，未知代理和本地部署不猜额度。上下文、输出上限、记忆配额是不同预算量，确认记忆最多 4096 tokens。修改预算算法须同时核对预留、记忆投影及四种协议上游参数。
- 工具循环压缩只修改请求投影。调用/结果 ID 必须完整配对，供应商原生签名/加密字段不丢；已归档大结果以合法预览、完整引用和分页入口替代。历史回查默认当前有效聊天公开正文，显式工作检索只增加按权限核验的同工作未归档来源；`includeTools` 可返回已记录的公开步骤、不可信观察及结果引用，不包含可见思考、私有续接、配置或凭据。截断参数不执行，返回的部分正文不记为 completed。
- 根任务的压缩事实、来源侧车、已加载工具及插话身份经登记检查点保存；重启复核任务、范围、模型连接、归档哈希与来源版本。程序恢复提示标为 `broker-control`，不能混入真实用户目标，也不重复注入整个旧回复；真实用户插话不依措辞过滤。
- 并行范围读取、扫描和后台推理全部结算或确认实际取消后才释放保护与资源租约；不能仅因等待 future 已取消就假称线程、原生会话或模型已退出。

主要入口：[正式记忆](../../../../apps/agent-core/src/storage/gateway_memory.rs)、[记忆合同](../../../../apps/agent-core/src/storage/memory.rs)、[请求压缩](../../../../apps/agent-core/src/models/gateway_context.rs)、[历史投影](../../../../apps/agent-core/src/models/gateway_protocol.rs)。

## 存储、迁移与凭据

- 未打包便携版本默认使用软件旁固定 `Data/` 与 `Extensions/`；正式 AppX/MSIX 包继续使用既有可写用户目录与 `.kynxa` 指针，程序载荷目录只用于运行文件。有效旧选择和旧数据优先保留。`storage.json`、`extensions.json` 的相对位置按各自指针目录解析；便携软件移动后随位置解析，正式包更新不改变持久位置，显式环境配置优先。独立预览显式指定 `KYNXA_APPLICATION_ROOT` 时使用副本便携规则，不读取正式用户指针。桌面使用 [ApplicationPaths](../../../../apps/desktop/Services/Data/ApplicationPaths.cs) 和 [StoragePaths](../../../../apps/desktop/Services/Data/StoragePaths.cs)，网关使用 [GatewayConfig](../../../../apps/agent-core/src/gateway_contract.rs) 和 [存储管理](../../../../apps/agent-core/src/storage/administration.rs)。子进程接收一致的指针、默认位置与维护锁；默认值不覆盖迁移后指针，显式Data/Model隔离保持扩展隔离。复用网关核对实际模型/扩展目录；不把个人盘符、用户名或下载目录写进生产路径。
- 外部关联工作文件夹存放项目文件，聊天和记忆继续归统一 Data。改变存储位置使用实际迁移流程，复制、验证后切换指针，并保留可恢复备份；不只改设置造成旧记录不可见。
- 保持自动初始化、版本判断、原子写入、链接路径检查和失败恢复。迁移须能处理重复执行或中途退出。
- 当前模型连接包含存储于 JSON 的凭据，列表接口有脱敏；不能声称已实现系统安全凭据库。开发日志、Git、文档和测试只使用虚构 Key，不输出真实连接文件内容。
- 凭据仅供相应模型服务请求认证，不进入聊天提示词。配置界面不要回显已保存原始 Key，保留既有更新语义。
- 工具权限由网关按每次请求固定的工作范围和权限判定；模型参数、MCP注解和Skill内容不能扩大授权。批准单次绑定调用身份，取消或范围改变后不得执行。文件代理与AppContainer终端是不同边界，配置的MCP程序不是沙箱进程。具体已实现范围见 docs/architecture/agent-tools.md，不把后续完整Host或检查点设计写成已完成。
