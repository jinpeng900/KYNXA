# 交互和数据约定

这些约定描述当前基线。用户要求调整其中行为时，同步修改相关实现和验证；其余行为继续保持。详细入口见 [前端维护说明](../../../../apps/desktop/UI-COMPONENTS.md)、[聊天与工作记忆](../../../../docs/architecture/chat-work-memory.md) 和 [网关说明](../../../../apps/model-gateway/README.md)。

## 侧栏、窗口与语言

- 最近、项目树、任务引用同一稳定聊天 ID 和同一记录，不能创建副本。任务显示当前工作聊天，剩余高度延伸至底部固定栏，超出才滚动。
- 项目选择和展开是独立状态；选择聊天、发送、重试、在任务中新增聊天不自动展开已折叠项目。最近默认收起，保留用户展开偏好。
- 新聊天先为内存草稿，立即在相应任务区显示；未发消息切换到其他工作时清理。首条消息提交成功后才正式保存并更新最近/未置顶顺序，单纯打开或切换聊天不更新 MRU。
- 置顶、手动排序、聊天归属与活动选择分别维护。流式开始、结束和 token 更新不重排项目/聊天。
- 悬停、焦点、选中和展开各有独立状态，复用已有按钮、图标、字号与菜单样式。新增操作需有键盘访问和可读自动化名称。
- 侧栏上下分隔拖动区只在有相关展开内容时存在；移动到分隔区才出现浅灰提示。最近/项目内部的分隔拖动不改变下面任务边界，尺寸受限并支持现有复位行为。
- 窗口临时变窄只约束当前显示尺寸，不覆盖用户保存的宽度。控件尺寸来自布局模块和样式资源，不在多处重复数字。
- 切换界面语言即时更新菜单、设置等界面文字，聊天正文、用户自定义名称、模型 ID、地址和凭据保持原内容。保留草稿、选中项、滚动及进行中的回复。
- 界面刷新按稳定 ID 保留行对象；不要在输入回调中清空整棵 TreeView，避免重复渲染和丢失状态。

主要入口：[WorkSidebarState](../../../../apps/desktop/Services/Presentation/WorkSidebarState.cs)、[工作侧栏](../../../../apps/desktop/Views/ShellPage.WorkSidebar.cs)、[布局状态](../../../../apps/desktop/Models/UI/LayoutState.cs)、[界面文本](../../../../apps/desktop/Services/Presentation/UiText.cs)。

## 聊天展示、选择与流式输出

- 主聊天由 [ConversationTranscript](../../../../apps/desktop/Controls/ConversationTranscript.cs) 的一个 WebView2 DOM 展示。Markdown、代码、表格与 KaTeX 公式保持可选文字；旧 `MarkdownReply`/原生图片公式只是兼容路径。
- 正式记录保存原始内容，呈现不改写源 Markdown/TeX。代码软换行适应聊天列，复制保留原始换行和缩进；公式完整选择复制原 TeX，部分选择复制所选可视内容。
- 用户与模型多条连续回复可跨消息选择。松开鼠标结束拖选，点击非交互空白清除选区；有活动选区时暂缓改变其 DOM，清除后应用最新内容。
- 打开聊天到最下面。从底部发送后随回复增长，用户主动上滚或选择内容时暂停跟随；不能每次 token 更新无条件滚到底部。
- 流式内容与最终内容走同一展示路径。正文、思考、完成、错误和中断状态分别处理，未闭合公式允许显示源码，最终完整块重新解析。
- 工具回复按模型轮次保存 `AssistantSegments`，公开思考、阶段正文和该轮工具保持真实顺序，最终正文独立。工具调用、审批和结果复用同一 round/order；并发结果可以乱序返回，但不能改变调用身份。新回复的 `Content` 为最终正文，阶段原文保留于消息段，旧消息缺少边界时保持兼容显示，不猜测或重写历史。
- 顶部用时从模型、上下文和工具目录准备完成后的首个流式消息段开始，不能从发送或传输 `started` 提前计时。运行中仅每秒更新用时文字，跨工具轮次、聊天切换和语言切换保持单调起点；终态停止刷新，成功时使用网关保存的 `DurationMs`，重新打开不重新计算。本机实时计时起点不写入正式日志。
- 主聊天执行中只展示近期阶段正文与紧凑活动，待批准动作不能被裁掉；整轮成功且有有效最终正文后移除过程显示，只显示最终正文及真实总耗时。复制与重新打开采用相同展示投影。失败、取消、截断不能按成功收束；正式阶段、思考、调用与结果不因隐藏而删除。选区冻结与上滚阅读锚点须在过程收束时保持。
- 快速切换时废弃过期解析结果；缓存有容量、身份和失效边界。保留未变化 DOM，不为新 token 重建整个页面。
- HTML、JS、样式和字体随应用打包。保持现有 Markdown 转义、导航/资源/权限拦截及链接协议限制，不能让回复内容引入脚本或远程资源加载。

主要入口：[TranscriptMarkdown](../../../../apps/desktop/Services/Presentation/TranscriptMarkdown.cs)、[transcript.js](../../../../apps/desktop/Resources/Transcript/transcript.js)、[transcript.css](../../../../apps/desktop/Resources/Transcript/transcript.css)。

## 正式记录与工作关系

- 网关是正式会话和目录的单一写入所有者。桌面上传元信息和新用户消息，不回写助手快照来覆盖网关生成状态。
- 未发送草稿不创建正式会话、索引条目或记忆文件；打开相关 UI 不能改变这点。
- 工作名、关联路径、模型/服务商切换和 Data 迁移不改变聊天/工作 ID。普通聊天及无文件夹工作有各自身份，不通过显示标题推断归属。
- JSONL 是正式消息事件来源；索引、上下文摘录和项目清单按各自权威来源重建。`catalog.json` 拥有目录元信息，`project.json` 是其投影，不能反向作为独立目录事实。
- 归属、删除、撤销、移动、归档及生成事务经过既有会话队列；不得在旁路直接移动日志后补 UI。
- 单网关拥有 Data 的前提不可悄悄变成多个进程同时写。新增多进程方案需要明确新的并发合同。

主要入口：[conversations.mjs](../../../../apps/model-gateway/data/conversations.mjs)、[runtime.mjs](../../../../apps/model-gateway/orchestration/runtime.mjs)、[data-layout.mjs](../../../../apps/model-gateway/data/data-layout.mjs)。

## 记忆、上下文与来源

- 完整聊天历史只属于当前聊天。同工作通过已确认工作记忆共享约定，不自动把兄弟聊天原文放进上下文；关系接口仅返回元信息。
- 聊天、工作、用户全局记忆范围独立。隐藏的无文件夹工作不提供共享工作记忆；工作归档后的共享记忆不注入。
- 只有用户明确确认的记忆才能持久化为已确认条目。助手输出、引用、代码块和普通对话不自动升级为长期事实；未来模型提取也必须保留确认边界。
- 创建、更新和删除遵循范围版本 `expectedRevision`。冲突重新加载并让用户决定，不自动用旧表单覆盖他人修改。
- 来源归档、删除、撤销和移出工作各有现有有效性规则，状态从后端读取，不把暂停使用误当成条目删除。删除保留撤销标记，旧请求重试不能恢复已删除记忆。
- 上下文预算构建只做请求投影，不截断正式日志。历史选择保留完整有效轮次及助手调用/工具观察配对；失败、中断草稿不当成功答案，已执行动作按真实回执状态保留，不自动重放。可见思考不当最终事实注入；私有原生续接不能进入公开接口或跨来源回放。
- `context.json` 当前为 `extractive-v2/schemaVersion:2` 可重建导航与原文摘录，不是模型语义总结或已确认长期记忆。缓存绑定全部成功历史、覆盖历史、当前请求和预算；回源 ID 不能伪造。旧 v1 从原记录重建，未来版本拒绝覆盖。长期记忆损坏明确失败并保留文件，不能当空记忆写回。
- 1M 只是配置预算，不代表模型自动获得对应能力。输出由 `output-budget.mjs` 统一计算，连接 `maxOutputTokens` 默认 262144（256K），显式保存的小值继续保留；小上下文、必要输入和已知供应商输出能力会降低实际输出。独立输入硬限须另行夹住，不能把总窗口当输入限。`model-capabilities.mjs` 只核对已验证官方端点/精确模型，未知代理和本地部署不猜额度。上下文、输出上限、记忆配额是不同预算量，确认记忆最多 4096 tokens。修改预算算法须同时核对预留、记忆投影及三协议上游参数。
- 工具循环压缩只修改请求投影。调用/结果 ID 必须完整配对，供应商原生签名/加密字段不丢；已归档大结果以合法预览、完整引用和分页入口替代。历史回查只限当前有效聊天公开正文，不包含可见思考、配置、工具内部记录及兄弟聊天；截断参数不执行，返回的部分正文不记为 completed。
- 并行范围读取全部结算后才释放会话保护；不要将这里的 `Promise.allSettled` 简化为会提前失败退出的 `Promise.all`。

主要入口：[memory-service](../../../../apps/model-gateway/data/memory-service.mjs)、[memory-repository](../../../../apps/model-gateway/data/memory-repository.mjs)、[memory-contracts](../../../../apps/model-gateway/data/memory-contracts.mjs)、[context](../../../../apps/model-gateway/models/context.mjs)。

## 存储、迁移与凭据

- 数据位置由用户配置、环境和平台默认值解析；桌面使用 [StoragePaths](../../../../apps/desktop/Services/Data/StoragePaths.cs)，网关使用 [storage.mjs](../../../../apps/model-gateway/data/storage.mjs)。不把个人盘符、用户名、下载目录或参考源码地址写进生产路径。
- 外部关联工作文件夹存放项目文件，聊天和记忆继续归统一 Data。改变存储位置使用实际迁移流程，复制、验证后切换指针，并保留可恢复备份；不只改设置造成旧记录不可见。
- 保持自动初始化、版本判断、原子写入、链接路径检查和失败恢复。迁移须能处理重复执行或中途退出。
- 当前模型连接包含存储于 JSON 的凭据，列表接口有脱敏；不能声称已实现系统安全凭据库。开发日志、Git、文档和测试只使用虚构 Key，不输出真实连接文件内容。
- 凭据仅供相应模型服务请求认证，不进入聊天提示词。配置界面不要回显已保存原始 Key，保留既有更新语义。
- 工具权限由网关按每次请求固定的工作范围和权限判定；模型参数、MCP注解和Skill内容不能扩大授权。批准单次绑定调用身份，取消或范围改变后不得执行。文件代理与AppContainer终端是不同边界，配置的MCP程序不是沙箱进程。具体已实现范围见 docs/architecture/agent-tools.md，不把后续完整Host或检查点设计写成已完成。
