# KYNXA 1.8.5

KYNXA is a personal agent assistant for Windows x64, combining cloud and local models, files, tools, and ongoing tasks.

## What's changed

- Interactive 3D previews for GLB, glTF, OBJ, and STL, with rotation, pan, zoom, and display controls. Blender previews require a local Blender installation.
- Improved image, media, and CSV/TSV previews, plus workspace tools for managing and exporting results.
- A refined desktop interface with consistent controls, file selection, and workspace navigation.
- Local-model preparation separates communication resources from model-loading budgets and reports preparation or resource waits.
- Existing task guidance, queues, saved progress, model connections, and extension settings remain available.

Local transcription resources are included. Some media formats require a separately installed FFmpeg.

## Build from source

Requirements: Windows x64, Git, .NET 10 SDK (10.0.100 or a later 10.0 SDK), Rust 1.88+ MSVC, and Visual Studio C++ build tools with the Windows SDK.

```powershell
git clone https://github.com/jinpeng900/KYNXA.git
cd KYNXA
git checkout v1.8.5
powershell -NoProfile -ExecutionPolicy Bypass -File apps/desktop/Build/build-desktop.ps1 -Action Run -Configuration Debug -Profile Full
```

Use `-Action Build` to build without launching. Offline builds need prepared SDKs, Cargo/NuGet dependencies, and a compatible resource pack passed with `-Offline -ResourcePackRoot "path\resources.zip"`.
