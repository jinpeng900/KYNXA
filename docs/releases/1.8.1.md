# KYNXA 1.8.1

KYNXA is a personal agent assistant for Windows x64, combining cloud and local models, files, tools, and ongoing tasks.

## What's changed

- Ordinary deliverables finish without unnecessary extra verification.
- Closing settings during loading no longer reports unsaved edits.
- Local-model replies improve context handling and process reuse.
- Tray exit saves ongoing work before the gateway shuts down.
- Task replies are clearer, with saved context and successful results retained.
- Cache handling reduces repeated work while preserving current permissions and content.

## Build from source

Requirements: Windows x64, Git, .NET 10 SDK (10.0.100 or a later 10.0 SDK), Rust 1.88+ MSVC, and Visual Studio C++ build tools with the Windows SDK.

```powershell
git clone https://github.com/jinpeng900/KYNXA.git
cd KYNXA
git checkout v1.8.1
powershell -NoProfile -ExecutionPolicy Bypass -File apps/desktop/Build/build-desktop.ps1 -Action Run -Configuration Debug -Profile Full
```

Use `-Action Build` to build without launching. Caches are reused; offline builds need prepared SDKs and Cargo/NuGet dependencies, plus a compatible resource pack passed with `-Offline -ResourcePackRoot "path\resources.zip"`.
