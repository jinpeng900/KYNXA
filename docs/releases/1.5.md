# KYNXA 1.5

本页是 **1.5 系列功能总览**。当前安装发行版为 **1.5.2**，正式安装文件见 [GitHub Release](https://github.com/jinpeng900/KYNXA/releases/tag/v1.5.2)，本次附件与模型身份修正见 [1.5.2 更新说明](1.5.2.md)。安装发行版与源码工程中的版本字段分别维护；旧安装文件不会因文档更新而改变内容。

## 本版变化

| 领域 | 当前实现 |
| --- | --- |
| 桌面与网关 | WinUI/WebView2 通过 HTTP/SSE 调用原生 Rust 网关；Rust 负责模型、工具、检索和正式存储，C# ToolHost 负责 Windows 原生操作。核心不依赖 Node，固定私有 Node 仅供扩展 MCP 和已核验的 JS Skill。 |
| 聊天交互 | 发送时先显示用户消息，处理 Enter、Shift+Enter 和输入法确认；模型准备复用通信连接，相关准备与取证可并行，普通聊天避免无关检索。历史补载和后台索引不应阻塞当前聊天。 |
| 本地对话模型 | 设置中的本地模型管理接通安装、导入、启用、删除及安装目录调整；内置目录列出 62 个模型变体及资源建议，覆盖小模型和高内存设备。启用后进入统一模型选择，运行时按选择和加载策略准备，空闲时减少权重驻留。 |
| 全局工具记忆 | 持久保存工具声明与成功、失败、耗时等汇总经验，重启后复用；配置、工具身份和启停变化同步更新。缓存只辅助发现和选择，不代替实时权限或工具执行结果。 |
| 大库检索 | `auto` 模式缺少 ANN 图时接纳后台准备，前台继续使用可用检索；相同图的请求合并，图就绪后切换，重启与更新按图身份和版本复用。向量分页读取采用稳定游标及对应索引。 |
| BGE 重排 | 保留原混合检索信号，使用名次融合，按来源分配候选；精确目标跳过不必要的重排，长片段使用查询相关窗口。原文、引用和未重排候选保留，源码默认不强制启用重排。 |
| 文档与网页 | DOCX、PDF、旧 DOC/PPT、表格、常见压缩包及网址复用统一解析与回读路径；图片和扫描 PDF 可使用 Windows OCR。格式和内容覆盖边界见专门文档。 |
| 构建与安装 | 公开源码通过 `build-desktop.ps1 -Action Build` 或 `-Action Run` 构建与启动；安装包由维护者生成 Windows x64 自包含 WinUI 载荷，配置软件、数据、工具位置和语言。基础载荷包含 E5/BGE、固定运行组件和浏览器，可选对话模型按用户选择下载。 |

调用关系、范围隔离和正式数据所有权见[原生架构](../architecture/native-gateway.md)与[团队边界](../architecture/team-boundaries.md)，本地模型操作见[本地模型管理](../architecture/local-models.md)。此处列实现变化，不把所有路径都表述为已在所有设备验收。

## 重排针对性验证

2026-10-16 已执行的检查如下；本次文档更新复用这些记录，没有重新运行模型或扩展测试范围。

| 检查 | 结果与范围 |
| --- | --- |
| 排序规则回归 | 4 项通过。 |
| 300 题历史真实 BGE 分数重放 | 原混合排序 Recall@10 为 82.03%，旧 BGE 硬排序为 83.64%，新融合为 83.03%。新融合相对原混合排序提升 3 题、退步 0 题；本组没有超过旧硬排序整体得分。该项重放已有模型分数，没有重新推理。 |
| 6 条中英文真实 BGE CPU 推理 | 3 条英文题及对应中文银标翻译；两种语言均为原排序 77.78%、旧硬重排 88.89%、新融合 77.78%。新输入的实际截断均为 0，原文与引用保留检查通过。 |

这组修正解决了重排硬覆盖与长片段输入问题，不据此宣称 BGE 普遍提高召回。用户提供的 Linux 40 英文、20 中文报告仍是另一组实验，不能与上述数据合并。大库 ANN 的语义质量与性能也需要分别评估；百万级存储容量不等于百万级语义召回验收。重排策略、默认值和 ANN 衔接见[检索架构](../architecture/retrieval.md)。这些记录重放和真实 BGE 检查来自维护者的验证工作区。

## 分发与升级

普通用户从 [1.5.2 Release 附件](https://github.com/jinpeng900/KYNXA/releases/tag/v1.5.2)取得 `KYNXA-1.5.2-windows-x64-setup.exe`，或使用 `KYNXA-1.5.2-windows-x64-online-setup.exe` 自动下载完整包，不需要自行安装 Rust、Node 或 .NET SDK。开发者拉取源码后使用[构建入口](../../apps/desktop/Build/README.md)的 `Build`／`Run` 操作；拉取源码不等于同时取得大体积运行资源和模型权重。

数据和用户工具默认使用安装位置下的固定 `Data`、`Extensions` 目录，也可在安装和设置中选择其他位置；升级保留已有选择。软件内置资源位于 `runtime`，与用户数据、工具和可选对话模型分开。目录解析、迁移和卸载保留规则见[安装器说明](../../apps/desktop/Build/Installer/README.md)。

安装程序和运行资源作为 Release 附件分发，不提交大文件至源码仓库。当前安装包未配置生产发行签名；旧设计文档包和压缩包不纳入源码仓库。验证范围以具体版本说明为准，安装包构建与应用启动验证不等于在每台设备上执行过安装器。
