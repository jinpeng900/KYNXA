# KYNXA 1.8.8

A desktop experience update for Windows x64.

## What's changed

- Refines rounded controls, theme colors, settings actions, pin markers, and connection deletion controls.
- Improves responsive workbench layouts and keyboard selection. Closing a preview releases its menus, and closed file, webpage, and changes tabs can be reopened.
- Adds reply-completion notifications to General settings and restores workspace Undo feedback after folder operations.
- Redirects repeated launches to the existing window instead of starting a second desktop instance.
- Adds main-window close preferences. The default remains hiding to the system tray without asking; close confirmation is available as an opt-in setting. Exiting retains the existing task pause and save flow.
- Fixes transcription-manifest hashing during runtime preparation.

The 1.8.7 gateway and existing external runtime resources are retained, including the attachment and reply fixes. Saved data, model connections, MCP services, and skills are preserved.

## Download

- [EXE installer](https://github.com/jinpeng900/KYNXA/releases/download/v1.8.8/KYNXA-1.8.8-windows-x64-setup.exe) — run directly to install.

## Build from source

Requirements: Windows x64, Git, .NET 10 SDK (10.0.100 or a later 10.0 SDK), Rust 1.88+ MSVC, and Visual Studio C++ build tools with the Windows SDK.

```powershell
git clone https://github.com/jinpeng900/KYNXA.git
cd KYNXA
git checkout v1.8.8
powershell -NoProfile -ExecutionPolicy Bypass -File apps/desktop/Build/build-desktop.ps1 -Action Run -Configuration Debug -Profile Full
```

Use `-Action Build` to build without launching. Offline builds need prepared SDKs, Cargo/NuGet dependencies, and the compatible resource pack passed with `-Offline -ResourcePackRoot "path\resources.zip"`.
