# KYNXA 1.8.9

A model training and reply reliability update for Windows x64.

## What's changed

- Adds the workbench training studio: prepare datasets, configure algorithms and parameters, monitor runs with live charts, and compare results. Available backends follow what the local Python environment provides.
- Lets you remove selected training sources in one action and delete saved datasets. A dataset used by a running job cannot be deleted.
- Delivers a written answer even when completion review does not pass. The task stays incomplete and can be continued, instead of the answer being lost.
- Judges work progress by actual results. New successful results count as progress, and only identical repeats count as stalling, so long tasks are not stopped early while runaway tool loops are still stopped.
- Requires a new message sent during a task to be acknowledged before more tools run, and asks again if it was not.
- Recognizes more tool call formats written as plain text, and accepts more valid forms of the task control footer.
- Fixes terminal commands failing to load dependencies in packaged development builds, and gives clearer guidance when no workspace terminal is available or a request is too large.
- Removes stale runtime files during builds and adds a development script for updating the desktop shortcut.
- Cleans up code comments and formatting across the project.

Existing external runtime resources are retained. Saved data, model connections, MCP services, and skills are preserved.

## Build from source

Requirements: Windows x64, Git, .NET 10 SDK (10.0.100 or a later 10.0 SDK), Rust 1.88+ MSVC, and Visual Studio C++ build tools with the Windows SDK.

```powershell
git clone https://github.com/jinpeng900/KYNXA.git
cd KYNXA
git checkout v1.8.9
powershell -NoProfile -ExecutionPolicy Bypass -File apps/desktop/Build/build-desktop.ps1 -Action Run -Configuration Debug -Profile Full
```

Use `-Action Build` to build without launching. Offline builds need prepared SDKs, Cargo/NuGet dependencies, and the compatible resource pack passed with `-Offline -ResourcePackRoot "path\resources.zip"`.
