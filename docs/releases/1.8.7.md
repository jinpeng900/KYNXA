# KYNXA 1.8.7

A maintenance update for Windows x64.

## What's changed

- Read uploaded images directly by their conversation attachment identity, including image regions, without searching private storage paths.
- Export original attachments to an authorized work folder for image processing and other tools. Existing files with different contents are preserved.
- Treat images without OCR text as valid images, including attachments previously cached as having no readable text.
- Continue interrupted tool proposals with the normal execution output budget; incomplete tool arguments are never executed.
- Preserve an already displayed normal reply when a control-format or progress check fails, instead of replacing it with a generic status message.
- Keep saved context, progress, successful operation receipts, existing permissions, and workspace presentation behavior.

## Download

- [EXE installer](https://github.com/jinpeng900/KYNXA/releases/download/v1.8.7/KYNXA-1.8.7-windows-x64-setup.exe) — run directly to install.
- [Compatible runtime resource pack](https://github.com/jinpeng900/KYNXA/releases/download/v1.8.5/KYNXA-1.8.5-windows-x64-resources.zip) — unchanged external resources for source builds. The gateway is compiled from the selected source version.

Windows may show an unsigned-app warning.

## Build from source

Requirements: Windows x64, Git, .NET 10 SDK (10.0.100 or a later 10.0 SDK), Rust 1.88+ MSVC, and Visual Studio C++ build tools with the Windows SDK.

```powershell
git clone https://github.com/jinpeng900/KYNXA.git
cd KYNXA
git checkout v1.8.7
powershell -NoProfile -ExecutionPolicy Bypass -File apps/desktop/Build/build-desktop.ps1 -Action Run -Configuration Debug -Profile Full
```

Use `-Action Build` to build without launching. Offline builds need prepared SDKs, Cargo/NuGet dependencies, and the compatible resource pack passed with `-Offline -ResourcePackRoot "path\resources.zip"`.
