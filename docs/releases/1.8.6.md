# KYNXA 1.8.6

A desktop-interface patch for Windows x64.

## What's changed

- Fixes opening the system folder picker when linking a work folder.
- Keeps one linked folder per work item and existing rounded controls with inline feedback.
- Reuses the 1.8.5 gateway, tool host, and runtime resources; saved data and model connections are retained.

## Download

- [EXE installer](https://github.com/jinpeng900/KYNXA/releases/download/v1.8.6/KYNXA-1.8.6-windows-x64-setup.exe) — run directly to install.
- [Compatible runtime resource pack](https://github.com/jinpeng900/KYNXA/releases/download/v1.8.5/KYNXA-1.8.5-windows-x64-resources.zip) — unchanged resources for source builds.

Windows may show an unsigned-app warning.

## Build from source

Requirements: Windows x64, Git, .NET 10 SDK (10.0.100 or a later 10.0 SDK), Rust 1.88+ MSVC, and Visual Studio C++ build tools with the Windows SDK.

```powershell
git clone https://github.com/jinpeng900/KYNXA.git
cd KYNXA
git checkout v1.8.6
powershell -NoProfile -ExecutionPolicy Bypass -File apps/desktop/Build/build-desktop.ps1 -Action Run -Configuration Debug -Profile Full
```

Use `-Action Build` to build without launching. Offline builds need prepared SDKs, Cargo/NuGet dependencies, and the compatible 1.8.5 resource pack passed with `-Offline -ResourcePackRoot "path\resources.zip"`.
