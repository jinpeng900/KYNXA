# KYNXA 1.5.2

本次补丁修复截图附件发送和模型身份说明，保留 1.5.1 的 WinUI 界面资源打包修正。

- 剪贴板截图改存系统临时目录，避免附件导入时被应用私有目录保护拦截。导入失败后保留草稿，重试仍会实际导入，收到完整回执后才清理临时截图。
- 主聊天、子任务及异常后的总结回复使用本次连接的 Provider、Model、协议和端点主机名说明身份。历史、摘要和记忆中的旧身份不能覆盖本次配置；连接配置不作为真实上游权重的认证，提示词不包含 API 密钥。

Windows x64 安装文件使用标准名称：

- `KYNXA-1.5.2-windows-x64-setup.exe`：完整离线安装包。
- `KYNXA-1.5.2-windows-x64-online-setup.exe`：在线安装入口，下载同版本完整安装包。

升级时使用原软件目录，保留已有数据、用户工具和模型。安装包通过 GitHub Release 分发，不纳入源码仓库。
