# 工作台与文件预览

右侧工作区可查看文件、网页和工作成果。工作台提供成果版本、资料收藏、模板、批量处理及手机连接，操作在当前页面内完成。

- 三维：GLB、glTF、OBJ、STL 支持旋转、平移、缩放、部件选择、材质与线框显示；Blender 工程需要本机 Blender 生成派生预览。
- 图片：缩放、旋转、裁剪、标注、比较及导出。
- 音视频：播放、字幕、时间标记和本地转录。完整运行资源包含 whisper.cpp 及 tiny 模型；部分媒体格式需要另行提供 FFmpeg。
- 表格：CSV、TSV 的筛选、编辑、统计、图表和导出。
- 文档和网页：沿用 Office、PDF、Markdown、Mermaid、浏览器及源码预览。

每个工作最多关联一个文件夹；也可通过系统文件选择器预览明确选择的其他文件。生成内容只在用户请求或适合交付时展示，不额外增加截图验收要求。

升级保留已有的存储、模型连接、MCP 和 Skill 配置。

工作台选择器支持方向键、Home、End、Enter 和 Esc；切换页面或关闭预览会收起菜单并释放监听。已关闭的文件、网页和变更标签可以重新打开。

回复完成通知默认关闭，可在“通用”设置中开启；点击通知返回已有窗口。关闭主窗口默认隐藏到托盘且不询问，可在“通用”设置中改为退出或主动开启“关闭时询问”。托盘退出仍沿用任务暂停与保存流程。

上传的图片既可直接分析，也可导出原始文件供裁剪、像素化等脚本处理。原件按会话和消息隔离，导出保留原始字节与校验值，不覆盖不同内容的已有文件。图片没有可识别文字时，只表示文字提取为空，不影响原图读取；分析和导出不会自动打开右侧预览。

完整构建沿用 `apps/desktop/Build/build-desktop.ps1`。转录资源通过 `prepare-transcription-runtime.ps1` 按固定版本和哈希准备，也可使用 `-Offline` 校验已准备的资源。
