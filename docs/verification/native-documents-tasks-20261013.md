# 文档解析与持久任务修正验收

2026-10-13，Windows x64。本轮使用独立临时 Data、工作目录和精确所属进程，不改日常聊天、凭据或运行中的工作。固定输入的服务回归与真实 API 验收分开记录，不将历史评测算作本轮成绩。

本报告覆盖本机开发实现。按用户“不提交 UI、只提交部分且不影响正常使用”的要求，main `634b49d` 仅提交六份开发规范和独立的读取观察修复；任务、解析、记忆及界面整套改动仍保留本地。下列开发验收结果不能被理解成这些能力已经全部在 GitHub 交付。

## 已实现行为

- 修正自动记忆候选的空消息 ID，贯通草稿、确认、更新、删除与授权范围读取。检索模型为随包 E5 与 BGE，不附带生成大模型。
- 统一资料格式注册、解析版本和原始字节身份。旧 DOC/PPT 使用活动结构解析；现代 Office、邮件、电子书、图像/PDF OCR、压缩成员和明确网址复用同一来源与索引链路。
- 持久任务与执行尝试分开。子代理拥有独立上下文、真实调用计量、审批与结果引用；成功及结果未知的副作用受正式账本保护。
- 桌面停止保存暂停断点；插话选择继续、更新方案或明确取消。恢复观察同一任务，不重发原聊天请求。短聊天保留内部幂等记录，按实际长输出、多步工作及需恢复状态进入任务侧栏。
- 最终正文与任务核验状态分开，部分成果同样显示正文。普通文稿不要求程序测试，代码修改仍核对实际版本及验证回执。普通文件回读不证明字数、质量或用户全部要求已满足。
- 工具目录属于版本绑定的运行配置，按需发现和加载，不写入个人记忆；减少重复宣布准备工具的正文。
- 压缩保留原始用户目标、来源侧车与回查入口，替换旧派生块；DeepSeek 工具续接保留供应商私有字段，程序资料块不冒充助手轮次。
- 当前工具轮次采用带原始引用的工作摘要，继承有效输入/输出限制；同来源、同版本和同范围不因包装回执轮换重复摘要，已处理内容随检查点复用。摘要帮助续接，不证明语义正确或用户要求已完成。
- 真实读取和逐文档分析保存为既有任务产物；根任务通过 `task.document` 记录、列出或分页回读成果。根检查点同时保存程序进度与工作摘要，恢复先复用成果再处理失效来源。重复内容不算进展，三轮停滞提示改策略，余下工具优先用于综合与验证。

详细合同见 [文档](../architecture/document-ingestion.md)、[压缩包与网址](../architecture/archive-and-url-ingestion.md)、[任务](../architecture/durable-tasks.md)。未支持或未覆盖的内容返回实际状态，不承诺所有专有格式、图片语义或音视频均能解析。

## 真实 API 与失败诊断
