# 模型训练台

在工作台中打开“训练”，按数据集、模型与结构、训练参数、训练监控、结果查看实验。训练页沿用软件主题、圆角卡片、滑动选中标识和窄栏布局，不新增操作弹窗。

## 数据与模型

- 支持选择资料文件或目录，以及直接输入文本、CSV、JSONL样本。PDF、DOCX、PPT等复用文档解析；扫描内容依赖已有OCR能力。
- 文本语料、问答对话、结构化表格和带标签或描述的原图分别组织。OCR文字不能替代图像训练。
- 保存数据集时清洗去重、记录来源和内容摘要，冻结训练、验证、测试划分。修改划分需要另存数据集版本；运行中的数据不会随原文件变化。
- 项目仍只关联一个工作目录。系统选择器允许导入明确选中的其他资料副本，不向模型开放整个资料目录或软件私有数据。
- 资料来源可勾选后批量移除，只改当前列表，不动原文件。已保存的数据集可在行内确认后删除，只有正在训练所用的那份不能删；此入口仅在训练页提供，聊天模型不能调用。作业保留自己的数据集记录，但未完成的图片实验依赖原数据集的图片，确认时会提示。
- 导入图片按需显示缩略图；勾选后才批量填写标签和描述。保存后的样本按页查看，显示表格真实列名、文本片段、图片及来源，清洗计数和缺标签单独列出。预览通过当前工作归属内的导入身份或数据集身份读取，不接受私有目录任意路径。

训练类型以环境探测结果为准：

| 后端 | 算法与能力 | 环境要求 |
| --- | --- | --- |
| 轻量CPU | MLP分类/回归、线性/逻辑回归、K-Means | Python标准库 |
| scikit-learn | 随机森林、梯度提升分类/回归 | numpy、scikit-learn |
| PyTorch | 可配置卷积层的图像分类网络 | torch、numpy、Pillow |
| Transformers | 本地文本监督微调 | torch、transformers、datasets、accelerate |
| PEFT | 文本LoRA；兼容CUDA设备的4bit微调 | 上述依赖及peft，4bit另需bitsandbytes |
| TRL | 支持架构的视觉语言监督微调 | 上述依赖及trl、Pillow |

已有本地GGUF主要用于推理，训练时选择匹配的可训练权重目录，包含模型配置、权重及分词器；图文模型还需processor。原始模型保留，微调结果另存。环境已安装不等于所有模型架构均受支持，开始前会检查实际依赖、资料和设备。

模型层数与解冻范围分开处理。自建网络调整各层宽度；预训练模型使用实际层索引与目标模块，LoRA另设rank、alpha和dropout。参数根据算法过滤，不把不生效的选项显示为可用能力。

## 操作体验

- 页面保留操作名称、必要单位和错误原因，删去损失原理及重复说明。监控页集中显示关键指标、进度和实时曲线；不适用的按钮隐藏。常用参数直接显示，随机种子、资源配置与完整JSON可展开调整，运行环境已就绪时默认收起。
- 数据页选好并保存资料后，可以直接进入模型设置。图片资料可逐张填写分类标签、图文描述，也可明确点击按父目录补充空标签；已有标签保留，私有导入目录不会被当作标签。
- 不同算法分别保存参数草稿。首次选择算法时读取训练器公布的实际默认值，避免将小网络的学习率、批大小带到大模型微调；实时指标默认显式设为每步记录。切换回原算法恢复已编辑参数。
- 输入按编辑实时保存。非整数轮数、无效学习率及层编号在字段旁说明；未修正时不能悄悄按之前的参数启动。数据划分在数据页设置并冻结，不因切换算法而改变。
- 启动时显示提交状态，同一操作等待期间不能重复派发；暂停、继续、停止互斥处理。实验切换与对照可展开，检查点等技术信息默认收起，把主要空间留给进度和曲线。
- 运行原因、实际进度和结果状态同步更新，完成后直接出现结果入口及受支持模型的试用入口。没有可靠剩余时间时不编造倒计时。
- 连接暂不可用时保留已有曲线和原实验，恢复的是状态读取，不重新启动训练。重复连接错误不刷屏，支持手动重连；不可见页面仍停止轮询。
- 参数页提供可编辑的“常规起点”和“轻量起点”，以及按当前数据、结构和权重计算的资源估计。预设只修改新实验草稿；自动设备尚未检查时会注明暂按CPU估算，不假定显卡可用。
- 结果页支持名称/备注/算法搜索、状态筛选、改名及备注。名称和备注独立保存，不改冻结配置。旧检查点先列出可回收数量，再由用户在行内清理；保留最新两份、所有续训引用、已登记产物与源数据。训练运行时不能清理；预览后文件变化须重新读取清理清单。

## 实时曲线

训练进程追加实际指标，训练页默认每秒读取新增记录；默认每步记录，可调整记录间隔。训练损失和验证损失分开绘制，支持悬停数值、查看范围、平滑显示和实验对照。原始指标不被平滑值覆盖。

平滑显示会叠加原始线；长记录抽点保留峰谷，不把损失尖峰抹平。聚焦图表后可用左右键、Home/End查看读数；相同数据不重复绘图。只有验证指标更新的记录也不会把上一次训练损失显示为空。SVG/PNG自带标题、图例和范围信息，空图不提供无效导出。

只有具备验证数据时才显示验证指标。非迭代算法展示实际报告的进度及评估，不补造loss。loss可能波动，不保证每个点都下降。

图表可导出SVG、PNG，指标可导出完整分页CSV；另有实验JSON和Markdown报告。导出冻结读取边界，不会因训练持续追加而无限追读。模型产物导出不覆盖已有文件。

可按起止步数缩放并标记实际采样点，标记和范围按实验保存；SVG/PNG包含标记线。“暂停图表更新”仅冻结视图，训练和后台指标追加照常进行，恢复时接上最新数据，与暂停训练是两个独立操作。

## 后台运行与恢复

训练开始后立即返回运行ID，不让一个聊天请求等待整轮训练。关闭训练页或切换聊天只关闭观察视图；暂停、停止通过原作业控制文件传达，不新建重复训练。

支持的后端在优化器步、迭代或检查点边界保存。检查点包括该后端恢复需要的模型、预处理、优化器、调度器、随机状态与数据游标；界面显示实际恢复能力。不同设备与框架版本可能影响数值复现，不承诺跨环境逐位相同。

窗口隐藏到托盘沿用原有后台运行策略；明确退出软件时，网关请求训练保存后退出。下次按原运行ID继续，保留指标、产物和已完成状态；失败不自动反复重开。

训练请求进入现有资源队列，按实际算法与权重估计内存/显存，登记进程采样；CPU进程使用较低优先级。等待资源与无法容纳的配置分开显示，不让不可能满足的配置长期占着队列。估计可在高级资源参数中调整，但不能保证训练对聊天完全没有性能影响。

## 聊天操控与结果

聊天模型按需发现`training.inspect`和`training.manage`，使用相同数据集和实验记录创建、启动、观察、暂停、续训和导出。询问训练方法不会自动启动训练。完成的作业保持完成，不因后续停止请求改回未完成。

支持独立预测的已完成轻量/树模型在结果页按真实特征填写表单，批量JSON保留在折叠区。字段与预处理来自冻结数据和训练产物。

兼容的文本HF模型和LoRA适配器可在训练台内部试聊；只有明确选择对比时，才分别运行原底座和训练产物。试用异步排队、可取消，限本地已授权权重，不下载模型，不注册或替换聊天模型，不改变训练状态。视觉语言产物暂不提供这种文本试聊入口；实际架构兼容性仍以加载结果为准。

## 环境与模块边界

训练Python与普通聊天运行时分开选择。可以通过训练台原生选择器指定已有解释器，也可以使用应用`runtime/training/python.exe`、本地训练虚拟环境或`KYNXA_TRAINING_PYTHON`。安装依赖不会在每次开始训练时重复执行。

工作台提供独立环境准备和取消入口，按所选训练后端安装固定依赖组合，显示设备、当前阶段、来源、可得的字节进度与有界日志。没有Python时，下载校验过的固定官方安装器，再安装固定Python；已有Python的内置轻量环境可离线建立。新环境写入`Data/Runtime/training-envs/<ID>`，成功后只原子切换当前训练归属；失败、取消或用户已改选解释器时保留原配置。实验在首次通过准备与资源准入后固定所用解释器，后续续训、预测和试聊仍使用它，避免另一后端的新环境影响旧实验。依赖准备失败时不提前绑定坏环境；已绑定解释器丢失则明确报告，不静默更换。下载复用已有系统代理/PAC设置，不修改聊天客户端或全局代理。Python与依赖联网下载仍受网络、代理和设备兼容性影响。

`apps/agent-core/src/training`分离数据集加工、资料导入、作业控制、资源估计、指标存储、预测及产物导出。`apps/agent-core/training-runtime`按后端拆分执行器，以版本化文件协议通信；脚本随网关编译嵌入，不使用开发机绝对路径。

桌面端的`training.js`负责页面协调；资料标注、分页预览、环境准备、参数预设、实验整理、结果试用、进度和图表分别放在独立模块。`training.css`样式限定在训练台，不覆盖其它工作台页面。只有可信的原生选择器可以登记所选资料和模型；网页请求不能自行扩展该授权。新增环境安装、数据预览、元信息维护、旧断点清理和文本试用仅供工作台使用，不加入聊天工具能力清单；既有模型操控训练工具保留。训练不修改聊天主循环、排队、引导或上下文缓存规则。
