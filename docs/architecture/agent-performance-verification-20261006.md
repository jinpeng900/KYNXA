# KYNXA 固定 DeepSeek 的 Agent 任务验收

2026-10-06 新增独立 `agent-system-v2`：12 类任务各两次，KYNXA／实际 Pi SDK 共 48 次运行，以及公开 SciFact 全量对照，见 [系统基准报告](system-benchmark-20261006.md)。旧五题与 v3 成绩不替代或重评分；新分数是严格输出／事实／执行合同，失败另做人工诊断。

本报告区分真实模型任务、检索组件和功能回归。真实任务使用用户明确授权的专用测试连接，凭据仅在内存中读取；各任务使用独立的合成 Data、工作文件和扩展配置，不启动或重置日常网关，不读取正式聊天。不提交或推送本轮工作。

## 实验合同

固定 `deepseek-flash`、生产 OpenAI completions 协议及默认采样参数。评测独立配置为 32,768 上下文 / 8,192 单次输出、每任务最多 12 次模型调用、24 次工具调用和 120 秒；没有改写用户正式模型连接的 256K 输出设置。

五类固定任务是简短招呼、英文资料中文问答、两轮实体续问、真实文件读→写→读回，以及无答案时停止猜测。检索关闭组仍可使用同一文件工具；开启组使用生产混合检索和实际离线 E5 向量，可选重排与网页均关闭。资料导入及嵌入准备单独计入 `setupMs`，任务时间、所有成功/失败调用用量均记录。

这组只有一个短合成文档，检索关闭组也能直接读取，因此可能出现正确率封顶。它是系统烟测和配置消融，不能当作 BrowseComp-Plus、LongMemEval-V2 或全产品 Agent 榜单，也不覆盖浏览器、桌面、持久长任务、真实仓库修复及全部语言场景。API 模型 ID 相同不保证供应商内部版本永远不变；默认采样仍有随机性。

## 根据实际失败做出的修正

- 纯文件/终端执行使用现有执行工具，省略自动检索无关知识资料；模型仍可按需使用知识搜索。代码分析、资料问答、历史/记忆查询及其续问保留检索。
- 工具/检索任务增加范围与语言提示：按当前请求语言回答、按要求提供深度、证据及必要验证充分时结束；减少未要求的额外比较和推导。它是模型提示约束，不保证所有回答都服从。
- 证据只在最终历史和工具 schema 预算确定后去重；防止一条事实先从证据移除、又在后续历史压缩时移除。范围/内容版本再次核验后，归档与最终提示一致。
- 普通裸 API 对话不添加上述工具提示，保留小窗口历史摘要的空间和原消息协议。

### 验收器 v3 的独立复核

复核发现 v2 对“分别不是”及同一正确人名的肯定/否定矛盾处理不足，首轮问答还可能仅凭人名出现放过错误归属。v3 收紧这些关系，支持明确实体标题下连续人物字段、表格和显式对照，区分否定发射状态与否定审查人。它仍只是固定资料的有限规则，不充当开放域语义裁判。日期、语言、引用和必需 ORION 命名不放宽。

两次模型运行均仅重新检查已保留答案，新增模型调用为 0；原文件和先前 v2 重评分字节保持。v3 分轮和总体成本重新分组，但全部调用用量不变。

- [首次运行 v3](../../artifacts/verification/agent-performance-benchmark/run-1791217851841-31c2955e/rescored.agent-verifier-reviewer-relations-v3.json)：关闭 5/5、开启 5/5。
- [重复运行 v3](../../artifacts/verification/agent-performance-benchmark/run-1791219385240-b94ff105/rescored.agent-verifier-reviewer-relations-v3.json)：关闭 9/10、开启 10/10，与该次原 v2 分数相同。

重评分保留原始运行的源码指纹，另记当前 verifier 源码摘要，不用后来的评测源码覆盖当时运行身份。输出文件版本化且只允许新建；CLI 指定已存在的输出目录会在任何模型请求前拒绝，避免覆盖旧报告或先付费后才发现不能保存。
