# 网页检索失败与未声明工具恢复

## 本轮确认的问题

2026-10-05 本机正式记录中，某次问答先完成两次搜索，随后两个公开网页读取均返回 `WEB_URL_BLOCKED`，第三次模型调用因为名称不在当轮声明目录中而直接报错，正文未形成最终答案。

第三轮原始失败名称当时没有落盘，不能断言它一定是某个浏览器或搜索工具。隔离复现确认：标准搜索两次查询用尽后再次请求历史中的搜索名称，可以触发同一错误。DNS 非公共答案拒绝是另一条独立原因，不能通过关闭 SSRF 防护修复。

## 已实现的恢复方式

- 每次模型调用只取得一次工具目录快照，生成声明和解码回复共用该快照。生成期间的预算变化不会改变已发出的工具名称解释；执行时仍检查实际预算、权限和配置代次。
- 格式完整但未声明的调用标为不可执行。它不能进入工具执行服务、隐式加载工具或取得额外权限。
- 保留调用和 `MODEL_TOOL_UNAVAILABLE` 失败回执，按供应商协议配对回传给模型。模型可以选择当前已声明的工具，或通过 `tool.search` 与 `tool.load` 显式发现、加载允许的能力。
- 两轮包含未声明调用后要求模型给出无工具最终回答，保留已核验信息并说明具体限制。供应商仍忽略无工具请求时，程序生成诚实的限制说明，不继续无休止重试。
- 拒绝的未声明调用不计入实际工具执行次数；调用尝试、公开阶段、失败回执与原生配对仍留在正式记录。
- 取消、存储失败、配置代次变化、重复执行身份、残缺已声明工具参数和未知副作用沿用既有边界；恢复未声明名称不扩大这些行为的授权。

这表示“完成一条有明确限制的回复”，不表示失败的网页读取或工具操作被宣称成功。普通用户后续消息和历史仍可继续使用。

## 搜索与浏览器的边界

普通联网问题优先使用搜索服务与公开 HTTP 文本读取。后台浏览器阅读和用户本机浏览器操作是不同能力；不能仅因为网页读取失败，就打开本机窗口或操作用户已有登录页面。

浏览器路由由工具层检查当前可信用户请求和已配置连接的类型；工具理由、网页文本、技能内容与未知服务描述不构成用户授权。普通网页读取只允许符合后台条件的连接；明确本机浏览器操作保留原有审批、页面身份与焦点规则。DNS 地址校验仍保留。

搜索浏览器品牌、查询文档和询问操作方法，不等于授权操作本机浏览器。“搜索 Chrome 最新版本”“Chrome 怎么截图”应保持普通问答；“帮我用 Chrome 截图”才是当前操作要求。普通检索可以使用已配置的隔离无头浏览器或非本机远程端点，不能静默转用用户的可见窗口或既有登录配置。

来源归一化按供应商标记的来源块或结构化对象提取标题、网址和摘录，避免把另一来源附近的文字混进摘录。无来源标签的文本只保留能确定的网址、Markdown 标题，不编造正文归属。

## 回归中修复的模型关闭问题

完整回归曾出现原生推理子进程异常退出。代码同时存在关闭时强制终止仍在推理的 Worker 的生命周期隐患；异常退出不能单凭一次日志归因，但这个可确认的隐患已经修复。

关闭现在先拒绝待处理请求，等待当前原生推理批次结束，释放输出张量和模型资源，再发送清理确认并自然退出。关闭超时返回 `EMBEDDING_CLOSE_TIMEOUT`，不会强行终止仍在运行的原生线程，也不会把未完成清理报告为成功。相同关闭请求共用一个完成状态。

离线模型加载、推理中关闭、取消后重试与存储维护测试已通过；随桌面包提供的 Node 运行时也完成了真实离线推理后安全关闭验证。

## 验证范围

使用临时数据与模拟模型/工具；覆盖三种模型协议的 HTTP/SSE 配对恢复、未声明工具不派发、反复请求后正常收束、生成期间目录变化、搜索两次用尽加 DNS 读取失败再请求历史工具的原始链路，以及后续聊天继续读取历史。

完整回归执行了 746 项：745 项通过，1 项旧测试仍要求无工具阶段的未声明调用中断。该预期现已按本轮需求更新；所属 HTTP、恢复和执行可靠性测试重新执行 17 项，全部通过，确认四次已执行操作不会因同一请求重发而再执行，第五次未声明尝试只保存失败回执，后续聊天保留原生配对历史。

最后复核补上方法咨询误授权用例后，浏览器策略、本机工具、连接发现、网页检索、8K 声明预算和执行回执测试另行执行 41 项，全部通过。本轮后续修改按实际影响复测相关测试，没有把旧完整回归的 1 项失败统计改称为当时全部通过。

完整回归明确排除真实可见终端用例，以及两个需要可交互本机桌面的原生验收用例。当前桌面能力探针返回不可交互，不能把它们记录为通过；其余桌面传输测试 11 项通过。桌面 Debug x64 构建为 0 警告、0 错误，架构检查与差异空白检查通过。

浏览器策略和来源块解析采用独立合成测试。真实代理 DNS、付费搜索和用户当前模型没有在这些模拟测试中调用；上线页面内容和答案质量仍需要实际工具返回的证据核验。
