# 本地对话模型管理

适用于 KYNXA 1.5 系列，当前安装发行版为 **1.5.2**，安装文件见 [GitHub Release](https://github.com/jinpeng900/KYNXA/releases/tag/v1.5.2)。这里的模型用于生成回答，与随基础载荷提供的 E5 嵌入、BGE 重排模型分开。既有云端 API 和外部 Ollama 等连接继续保留；使用自管本地模型不要求安装 Ollama。

## 设置与安装位置

设置中的本地模型子页提供总开关、安装位置、加载策略和模型列表。当前目录 `apps/agent-core/src/models/local_model_catalog.json` 列出 62 个变体，包括通用、代码、推理和视觉类别，以及较大内存设备可选择的模型。下载大小、建议内存和显存是选型信息，不是本机性能或兼容性验收结果。

默认安装库是配置模型目录下的 `Local`，常规布局为 `Data/Models/Local`；库清单为模型目录下的 `local-models.json`。路径来自统一配置，不能写死盘符或用户名。用户可修改安装位置，并选择迁移已管理的文件；目录的相对记录按当前模型根解析，外部位置使用绝对路径。

| 操作 | 行为 |
| --- | --- |
| 安装 | 从固定目录读取该变体的文件和下载来源，后台下载并显示状态；支持暂停、继续和取消。尚未完成的模型不作为已安装模型启用。 |
| 导入 | 读取已有 GGUF，支持复制进库或保留外部引用；分片和视觉投影文件按实际输入处理。导入任意 GGUF 不自动授予工具能力。 |
| 启用 | 校验就绪权重，注册为统一模型连接，聊天的模型选择中出现该项，不要求用户手填端口。 |
| 停用或删除 | 移除相应启用连接并结束自管执行；删除仅清理本库拥有的模型文件，外部引用的原件保留。 |

界面属于现有设置页，可返回设置；沿用项目中性配色和圆角，不新增系统风格的蓝色确认边框。

## 加载与空闲资源

运行时由 Rust 管理固定版本 llama.cpp，仅监听本机端口；CPU、Vulkan 后端选择与资源申请由现有模型和资源服务协作。软件不为目录中的每个模型都启动进程。`auto`、`on-demand`、`preload` 是加载策略字段；启动准备结合当前选择和实际资源判断，显式按需模式不提前加载全部权重。

自管服务使用空闲休眠：当前启动参数 `--sleep-idle-seconds 300` 允许权重在空闲后卸载，服务保留唤醒入口。后续选择模型或发送请求按需要唤醒；启用不等于一直占满内存和显存，也不等于立即完成装载。进程状态和模型准备状态分别展示，实际后端或失败原因以回执为准。

API 模型准备只复用配置、凭据与通信连接，不发送预热生成。E5/BGE 的索引和查询资源继续由[检索架构](retrieval.md)管理，不随切换对话模型重建向量空间。

## 模块与接口

以下列出安装发行版的模块职责，路径用于说明实现位置；公开源码中是否已包含对应模块，以当前检出的文件为准。

| 模块 | 职责 |
| --- | --- |
| `apps/agent-core/src/models/gateway_local_models.rs` | 库清单、安装和导入状态、启停、迁移与连接注册 |
| `gateway_local_download.rs` | 权重下载、暂停和续传 |
| `gateway_local_engine.rs` | llama.cpp 生命周期、后端和空闲休眠 |
| `gateway_preparation.rs` | 当前选择的后台准备与配置失效 |
| `apps/desktop/Services/Models/LocalModelsApiClient.cs` | 桌面模型管理通信 |
| `apps/desktop/Views/LocalModelsPage*` | 设置内的模型列表、进度和操作 |

`GET /api/local-models` 返回当前清单与状态；其余操作采用 `POST /api/local-models/settings`、`import`、`install`、`enable`、`delete` 和 `download`。桌面使用既有客户端接线，不另存一份正式安装账本。字段、状态和错误合同以对应原生入口与客户端为准。

EXE 安装器默认不勾选大型对话模型。用户勾选后保存首次启动任务，由软件通过同一管理接口后台下载并启用；基础 E5/BGE 和运行资源来自安装载荷。安装流程和重试日志见[安装器说明](../../apps/desktop/Build/Installer/README.md)。
