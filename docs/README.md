# KYNXA

KYNXA 是面向 Windows x64 的个人智能体助手，支持云端与本地模型、文档处理、项目检索、工具调用和持续任务。

每个工作最多关联一个文件夹，也可以不关联。关联、更换和取消关联在工作区内完成；取消关联只移除绑定，不删除文件。

工作侧栏各列表默认最多显示四行，可拖动分隔线展开更多，双击恢复默认高度。
