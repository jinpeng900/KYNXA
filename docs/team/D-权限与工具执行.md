## 最小工具集与权限语义

首轮只开放 `file.list`、`file.read`、`file.apply_patch`、`process.run_test`，均绑定 Work 范围。文件写入要带期望原文件哈希；测试命令使用可执行文件和参数数组、固定工作目录、有限环境、时间和输出上限。

“请求批准”在需要写入或执行时明确询问；“帮我批准”只能依据已定义的低风险规则；“完全访问”也不能绕过范围、审计、版本和去重。具体策略由 A/D 首周确认；尚未支持的模式应禁用或明确说明，不能假装可用。

检查规范化路径、重解析点与执行前实际目标；命名管道或本机端口要校验调用方。Windows Job Object 可用于子进程管理和资源约束，**并不等于完整的文件系统或网络沙箱**。没有真正隔离时只跑团队检查过的示例仓库，不向用户开放任意项目脚本；一般仓库执行作为另行验收的能力。

凭据用 Windows Credential Manager 或按当前用户保护的 DPAPI 方案，具体选型写入 ADR。C# / Node / Rust 间只经受控入口短暂取用；不以日志、错误文本或普通模型列表返回密钥。旧明文配置迁移先验证可调用，再去除活动配置中的明文字段；受控备份的保留与清理必须记录，不能声称旧副本自动消失。
