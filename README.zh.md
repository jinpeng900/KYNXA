# KYNXA 1.8.1

<p align="center"><a href="./README.md">English</a> | 中文</p>

KYNXA 是 Windows 个人智能体助手，将聊天、文件、工具和持续工作整合在同一个桌面应用中。

## 可以做什么

- 连接云端 API，或使用支持的本地模型。
- 处理多步骤任务，接受中途引导，暂停后继续已有工作。
- 检索项目文件与资料，使用限定范围的记忆和来源引用。
- 创建和预览文档、表格、演示文稿、图片与网页。
- 调用 MCP 服务、应用技能、浏览器工具和本机终端。
- 在右侧工作区查看文件、网页及终端会话。
- 主窗口隐藏后，通过系统托盘继续运行。
