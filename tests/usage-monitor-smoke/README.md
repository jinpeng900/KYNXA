# 用量统计核心冒烟

从仓库根运行：

```powershell
dotnet run --project tests/usage-monitor-smoke/UsageMonitorSmoke.csproj
```

使用独立临时目录和合成用量事件，不读取用户数据，不运行网关或模型请求，不启动窗口。

检查真实 0 与未知、独立输入和输出覆盖、失败请求已有用量、总量与缓存冲突、加权缓存率、稳定调用去重与 100,000 项边界、UTF-8 字节分片、半行、超长行恢复、EOF 历史跳过、截断/轮换/首次创建，以及宿主管道快照的 64 KiB 上限、坏命令恢复和准确关闭命令。

WPF 的真实拖动、折叠、菜单、主题、宿主退出和晚开启一致性由桌面集成验收检查；Core 检查不能替代实际界面操作。
