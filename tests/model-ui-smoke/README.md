# 模型配置原生窗口验证

在仓库根目录运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/model-ui-smoke/run.ps1`。此参数仅作用于该脚本进程，不更改系统执行策略。

使用临时 Data、临时扩展目录和独立 HTTP 模拟网关，不访问日常配置或真实模型 API。真实 WinUI 控件验证按所选具体模型设置新连接的上下文、混选取最小窗口、模型复选框及手动编辑、旧连接与手动设置保留、未知代理和本地默认、上下文与输出独立、保存/测试载荷、非法输入、忙碌状态、语言切换与草稿、窄窗滚动、关闭及晚到响应。结果和截图写入脚本返回的临时测试目录。

新增检查覆盖切换连接、切换服务商、新增连接和原生关闭的未保存编辑保护；取消时保留模型选择、密钥及自定义 token 草稿，确认丢弃不自动保存。520 DIP 窗口验证已保存连接下拉选择、自定义 token 纵向排列和固定保存按钮，调整尺寸按窗口实际 DPI 换算。

配置状态检查覆盖“尚未保存”“未保存的修改”和“已保存”标签，核对编辑后变为 dirty、显式保存后恢复 Saved；标签只说明配置保存状态。长连接名称和模型 ID 使用完整模拟数据，检查显示截断、完整提示和保存载荷不变。缺少名称、错误连接 ID、错误地址及缺少密钥时，验证校验失败不会发起请求，并定位原字段；隐藏的连接 ID 会展开高级设置，非法自定义输出也会返回原输入框。480×440 DIP 英文短窗验证完整连接提示、可滚动表单，以及添加、获取模型/测试和保存按钮的实际可见范围。
